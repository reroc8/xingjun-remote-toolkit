# 星君常用远程工具

> 一个单文件的 Windows 批处理菜单工具，把远程协助时最常用的排查动作收进一个编号菜单里。
> 作者：星君 (Xingjun) · 站点：<gp45.ys168.com> · 许可：MIT

日常远程帮人看机器，来来回回就是那几件事：查 IP、查 DNS、看防火墙、放行端口、查端口占用、看看远程桌面开没开。
每次都要回忆命令、翻笔记，效率很低。这个小工具把这些动作做成菜单，敲个数字就能跑，不用记命令。

**当前版本：v1.6**

## 使用方法

1. 把 `.bat` 文件放到桌面或任意目录（程序会在同目录下自动建一个 `导出` 文件夹，用来放导出的文本报告）。
2. 双击运行。**需要管理员权限的功能，请右键 → 以管理员身份运行**，否则会提示权限不足。
3. 按菜单提示输入序号后回车。功能执行完会停在结果页，按任意键回到菜单。
4. 输入 `0` 退出。

> 文件编码为 GBK，程序启动时会自动切到 `chcp 936`，中文显示正常。
> 如果你的系统区域设置不是中文，中文界面可能显示为乱码，属正常现象。

## 注意事项（重要，用前请读）

1. **本工具只修改本机配置，不联网、不上传任何数据。** 所有操作都是调用 Windows 自带命令（`ipconfig` / `netsh` / `reg` / `sc` / `schtasks` / `taskkill` 等）完成的，脚本内容可以直接用记事本打开逐行核对。
2. **改配置类功能请务必看清提示再确认。** 关闭防火墙、禁用系统更新、禁用 UAC 这类操作会降低系统安全性，程序在每一步都做了二次确认（要求输入 `Y` / `OFF` 等），不要习惯性回车。
3. **禁用 UAC 有副作用。** `EnableLUA` 设为 0 后，所有程序都会静默获得管理员权限且无任何拦截，同时微软商店 / UWP 应用大概率打不开。这是禁用 UAC 的固有现象，不是本工具的问题。用完请及时用功能 22 恢复。
4. **改 UAC 和系统更新需要重启才生效。**
5. **功能 13 结束进程是不可逆的。** 结束前程序会列出 PID 对应的进程名让你确认，请确认无误再输入 `Y`。系统关键进程被结束后可能导致蓝屏或需要重启。
6. **功能 24 会重启资源管理器**，桌面和任务栏会闪一下，属正常现象，正在打开的资源管理器窗口会关闭。
7. **功能 19 禁用更新不是永久的。** 部分 Windows 版本会自动把 `wuauserv` 服务恢复回来，如果发现更新又生效了，重跑一次即可。
8. **功能 12 放行的防火墙规则需要手动删除**（程序执行完会打印删除命令），规则名格式为 `星君放行_协议_端口`。
9. **建议在虚拟机或可回滚的环境先试。** 尤其是 UAC 和防火墙相关功能。
10. 部分安全软件可能会把这类批处理脚本报为可疑（因为它会调用 `reg add` / `taskkill` 等命令），这是误报，可以加入信任。

## 常见问题

**Q：双击后窗口一闪就没了？**
A：说明脚本在启动阶段就出错了。请打开命令提示符，把 `.bat` 文件拖进去回车运行，这样能看到报错信息。

**Q：提示"未检测到管理员权限"？**
A：右键文件 → 以管理员身份运行。查配置类功能不需要管理员，改配置类（防火墙、UAC、更新、箭头）都需要。

**Q：功能 5 刷新 DNS 后断网了？**
A：`ipconfig /release` 会先释放 IP，`/renew` 再重新获取。如果获取失败，重启一下网卡或路由器。这也是为什么这个功能要求管理员权限并做了提示。

**Q：导出的文件在哪？**
A：`.bat` 文件所在目录下的 `导出` 文件夹里，文件名带时间戳。
